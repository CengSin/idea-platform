# 白板与作品迭代实现记录

## 本轮实现

- 首页按公开来源作品组织项目家族：图钉便签 → 夹子作品卡 → 衍生便签。公开来源不可见时保留独立想法，不向游客传递私有来源 ID 或标题。
- 搜索保留项目关系，深层匹配展开祖先；循环和断开的历史数据不会造成无限递归或丢失条目。桌面可横向滚动、缩放、展开并用 Escape 退出；手机纵向排列。
- 工作台导航、想法详情、作品详情/列表、承接、管理、配置、设置和登录统一使用暖白纸张、柔和便签和细线。无真实封面时使用笔记本风格占位图。
- 作品变更追加元数据版本；新衍生想法绑定确定版本，Context 读取绑定快照。旧衍生想法标注历史版本未记录。
- Bootstrap v4 提供按分支授权的迭代草稿 POST/GET 接口。稳定 request_id 去重，仅通知作者。作者可编辑、发布或删除；公开写操作、执行验收和停止的授权模式不变。
- Turso 增量迁移、MySQL bridge 及 Go 原生作品更新保留版本字段。

## 验证

- Node：77 项测试通过，包含版本快照、不重复增版、草稿隔离、来源约束、幂等性、Turso 往返及深层白板关系。
- Go：`go test ./...` 通过。
- Next：生产构建通过；生产服务器实测 Agent 草稿创建/读取、重复请求、跨分支拒绝、发布字段拒绝、版本读取、作者发布后状态、游客页面不包含草稿正文。
- 浏览器：桌面和 390px 手机首页、搜索/缩放/展开、作品版本展开、Agent 草稿发布、承接、管理配置和设置页面已检查。
- 测试仅使用 `/tmp` 下的隔离应用与合成账号、作品，未修改线上内容，也未部署。

## 边界

版本保存平台说明、许可与链接，不保存 Git 仓库或部署文件。链接内容可能变化，固定源码应使用提交或发布标签 URL。删除来源作品后，已公开迭代保留独立记录，尚未发布的绑定草稿不再允许发布。

游客隐私断言使用生产构建验证。Next 开发构建可能在 React 调试流中带出服务端 IO 的调试值，因此开发环境只用于隔离测试，不应作为公开服务。
